# اختبارات الموقع

هذا المجلد فحوص آلية للموقع. **لا يعدّل الموقع** ولا يرفع شيئاً ولا يرسل بيانات إلى Google Sheets.

## ما الذي يُختبر وما الذي لا يُختبر

| النوع | ماذا يعني |
|---|---|
| **متصفح حقيقي بلا شبكة** | Chromium يفتح `index.html` محلياً. كل طلب خارجي محجوب. |
| **إرسال الشيت مُلتقَط** | دالة `sendToSheet` تُستبدل داخل الصفحة فتسجّل البيانات بدل إرسالها. يثبت ما **يرسله الموقع**، لا ما يفعله Google. |
| **شبكة وهمية** | خادم شيت مزيّف يردّ على الطلبات (T8b). يثبت الطلب الذي يرسله الموقع فقط. |
| **مقارنة ملفات** | T11a يقارن أسطر الملف الأصلي بأسطر الملفات الجديدة بدون ترتيب (T11). |
| **يدوي (MANUAL)** | Google Sheets الحقيقي: الإرسال والاستيراد والحذف. **لا يُعتبر ناجحاً** إلا إذا نفّذه شخص على الموقع المنشور. |

الاختبارات الآلية تثبت الحدود والحفظ والإرسال داخل الموقع. لا تثبت أن Apps Script يحفظ الصف الصحيح، ولا أن الشيت يتصرف كما نتوقع.

## المتطلبات

- Node.js 18 أو أحدث (يشمل npm)
- إنترنت للتثبيت الأول فقط
- Windows أو Linux

## التثبيت

افتح الطرفية داخل مجلد `tests` ثم نفّذ الأوامر:

**Linux / macOS:**

```bash
cd tests
npm install
npx playwright install chromium
```

**Windows (PowerShell):**

```powershell
cd tests
npm install
npx playwright install chromium
```

Linux (إذا طلب المتصفح مكتبات النظام):

```bash
npx playwright install --with-deps chromium
```

إذا كان عندك Chrome أو Chromium مثبت وتريد استخدامه بدلاً من المحمّل، اضبط `CHROME_PATH` (اختياري):

```bash
CHROME_PATH=/usr/bin/chromium npm test
```

```powershell
$env:CHROME_PATH="C:\Program Files\Google\Chrome\Application\chrome.exe"; npm test
```

## التشغيل

افتراضياً يفحص المجلد الذي يحتوي على `tests` (أي مستودع الموقع). الأوامر أدناه تفترض أنك داخل مجلد `tests`. إذا كان المجلد في مكان آخر، اضبط `REPO_DIR`.

لإضافة مقارنة T11 مع الملف الأصلي الأحادي (`index.html` قبل التقسيم)، اضبط `ORIG_HTML`.

**Linux / macOS:**

```bash
npm test
REPO_DIR=/path/to/site ORIG_HTML=/path/to/original.html npm test
```

**Windows (PowerShell):**

```powershell
npm test
$env:REPO_DIR="C:\path\to\site"; $env:ORIG_HTML="C:\path\to\original.html"; npm test
```

النتائج تُكتب في:

- `report.md`: تقرير بالعربية، فيه الجدول والفحوص كلها وخطوات Google Sheets اليدوية
- `results.json`: النتائج الخام

الخروج برمز `1` إذا فشل أي فحص آلي. التخطي (`SKIPPED`) واليدوي (`MANUAL`) لا يفشلان التشغيل.

## الملفات

| الملف | ماذا يفعل |
|---|---|
| `run_all.js` | يشغّل كل الاختبارات، ويكتب التقرير و`results.json` |
| `lib.js` | أدوات مشتركة: فتح المتصفح، حجب الشبكة، تسجيل الفحوص |
| `t1_scoring.js` | حدود النجاح: 0، 25، 32، 33، 50 إجابة صحيحة. يتحقق من النص والنسبة والدائرة والنتيجة المحفوظة والقيم المرسلة للشيت |
| `t7_smoke.js` | كل الشاشات في كل اللغات السبع، بلا أخطاء في الصفحة |
| `t8_records.js` | السجل المحلي: تحميل نتائج قديمة، إضافة نتيجة جديدة مع بقاء القديمة كما هي، بقاؤها بعد إعادة التحميل، المسح بضغطتين |
| `t8b_sheet_delete.js` | الحذف من الشيت: طلب واحد، يستهدف الصف الصحيح فقط (شبكة وهمية) |
| `t9_details.js` | تفاصيل الإجابات الخاطئة لكل أنواع الأسئلة، 5 اختبارات عشوائية، مقارنة بنص مبني من بيانات الأسئلة |
| `t11_parity.js` | مقارنة الملف الأصلي بالملفات الجديدة: حرفياً ودلالياً (يحتاج `ORIG_HTML`) |
| `report.md`, `results.json` | تُكتبان عند كل تشغيل |

## إضافة الاختبارات إلى المستودع

إذا وُضع المجلد `tests` داخل مستودع الموقع، فالتشغيل الافتراضي يعمل مباشرة. ملف `.gitignore` داخل المجلد يستبعد `node_modules` و`report.md` و`results.json` من Git.
